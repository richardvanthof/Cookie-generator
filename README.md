# The Great Bitwise Bake-off
An assignment for Computational Creativity.
A Leiden University course.

Authors: Daniel Aziel, Alberto Dorsi & Richard van 't Hof

## Introduction & concept
Within the project "The Great Bitwise Bake-off" we have been challanged the most creative recipe for a baked good like a cookie or cake using an evolutionary algorithm, which we had to transform present as a recipe. Within out project we took inspiration in Daniel and Richard's (partial) Indonesion heritage by making cookies based on Indonesian drinks and pastries.
